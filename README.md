# Irregular Sudoku

A TypeScript/Vite puzzle studio and a separate `/techniques` reference page.

```sh
npm install
npm run dev
npm test
npm run build
```

## Generate and solve

Generate starts with a blank 9×9 grid, constructs a random region map by
swapping boundary cells while preserving nine connected regions of nine cells,
and fills it using randomized minimum-remaining-values backtracking. Layouts
that are unsatisfiable or exceed a search budget are discarded. Generation runs
in a cancellable Web Worker and has a 100-layout limit. The distribution is not
uniform over all possible region partitions.

The completed grid is then dug in a shuffled cell order. Each removal is kept
only when exhaustive solution counting (stopping at two solutions) proves exactly
one solution. All 81 cells are tested. A failed removal cannot become possible
after further removals, so the result is single-clue minimal, not necessarily a
globally smallest puzzle. Digging has no search cutoff and can be cancelled.
The interface shows remaining givens, nine regions (cages), and total generation
time including construction, solving and digging.

Clear digits to enter your own clues, then Solve grid to find one
completion. Conflicting or unsatisfiable clues produce an error; search budget
exhaustion is reported separately. Undo restores previous grids. Grid state is
saved locally when browser storage is available.

JSON import/export uses `values` (81 integers, 0 for blank, 1–9 for digits) and
`regions` (81 region IDs 0–8), both in row-major order. Imports validate region
size and edge connectivity. This also allows solving externally authored layouts.

## Technique import

All 80 technique descriptions, ratings, glossary data and the classic engine
are imported from AImenes/sudokUI at commit
`cf7ce55e09ee7ea879327f4f995f9e603d4fb17a`. See
`vendor/sudokui/NOTICE.md` and `LICENSE` (GPL-3.0). The techniques page preserves
upstream descriptions and implementation status. Classic finders are retained
as source, not executed on irregular grids: geometry-dependent techniques need
adaptation and uniqueness techniques require a unique puzzle.

The site's source download is generated by `scripts/source.mjs` before builds.
Static hosting must serve `index.html` for `/techniques` (Vite does so locally).

## Validation

Tests cover 40 partition seeds, 20 complete generated grids, all 27 units per
grid, solving partial grids while preserving clues, invalid/disconnected region
maps, duplicate digits, bounded-search errors, and completeness of the 80-entry
technique import. Digging tests independently recheck uniqueness and remove every
remaining clue to verify minimality on three seeded irregular grids.

## Clipboard

Copy string writes exactly 162 characters: 81 row-major region IDs (1–9), followed
by 81 row-major cell values (0 means blank), with no separator. JSON retains the
existing zero-based region IDs. Copy image writes a 936×936 PNG of the current
digits and region boundaries, respecting the region-colors toggle (on by default).
If clipboard permission is unavailable, text is selectable manually and the PNG
is downloaded instead. Clipboard copying requires a secure browser context.

## Solution walkthrough and difficulty

Every generated puzzle receives an immutable solution trace in the worker. A
separate slider board shows the original clues at step zero and the exact board
and candidates after each deduction, with pattern/changed-cell highlights and
crossed-out eliminations. First/previous/next/last buttons and keyboard range
controls navigate without changing the editable puzzle. Restored generated grids
are reanalyzed automatically; edited/imported grids can use Analyze walkthrough.
Only uniquely solvable grids receive a rated trace. Undo can restore cached traces.

The region-aware logical engine supports Full House, Naked/Hidden Singles,
Locked Candidates, Naked Pairs/Triples/Quadruples and row/column X-Wings. When
these stall, it explicitly tests a cell's candidates by exhaustive search and
records which have zero completions. This guarantees a complete walkthrough
without pretending search is a human technique. Search runs in the cancellable
worker with no cutoff that could confuse an incomplete search with a proof.

Ratings are **Studio estimates for the recorded path**, not certified HoDoKu
ratings or claims of minimum human difficulty. Logical steps use imported
sudokUI weights and level/total-score thresholds. Search adds 1,000 points per
check and overrides the rating to **Search-assisted**. Each step displays its
technique, difficulty and points; the panel displays the aggregate and technique
counts. Generation time excludes walkthrough analysis. Tests replay every step
and ensure all eliminations preserve the known unique solution across five seeds.
